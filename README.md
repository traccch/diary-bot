# 🩺 Дневник давления

Телеграм-бот для личного дневника артериального давления. Пишешь ему
`120/80 68` — он разбирает цифры, время и комментарий, показывает категорию по
шкале кардиологов, напоминает измеряться и собирает выгрузку, которую не стыдно
отдать врачу: PDF со сводкой, графиком и таблицей всех измерений.

Python 3.10+, [aiogram 3](https://docs.aiogram.dev), SQLite, matplotlib.
Внешних сервисов не требует, данные лежат в одном файле рядом с ботом.

## Что умеет

**Запись одним сообщением.** Порядок слов не важен, лишнее уходит в комментарий:

| Сообщение                          | Что запишет                                |
|------------------------------------|--------------------------------------------|
| `120/80`                           | давление, время — сейчас                   |
| `120/80 68`                        | ещё и пульс                                |
| `120 80 68`                        | можно вообще без разделителей              |
| `120/80 п68` · `120/80 пульс 68`   | пульс явно                                 |
| `130/85 вчера`                     | вчерашним днём                             |
| `130/85 21:30`                     | своё время                                 |
| `140/90 15.08 09:00 после кофе`    | дата, время и комментарий                  |
| `давление 120 на 80`               | «давление», «на» — служебные слова, отбросит |

Ерунду не пропустит: `80/120` — подскажет, что цифры перепутаны, `400/200` —
что таких значений не бывает. `/add` — пошаговый ввод, если формат вспоминать
не хочется.

**Категория по шкале ESC/ESH.** Каждое измерение получает категорию
Европейского общества кардиологов — от «оптимального» до «АГ 3 степени», с
цветным маркером. При значениях от 180/120 бот не молчит: советует перемерить
и напоминает про скорую. Отдельно ловит изолированную систолическую гипертензию
(верхнее высокое, нижнее в норме) — её легко не заметить глазами.

**Напоминания.** `/remind 08:00` и `/remind 21:00` — обычная схема «утром и
вечером»; сколько нужно, столько и добавишь. Работают по часовому поясу
пользователя, переживают перезапуск бота и не задваиваются. Если измерение уже
было в последние полтора часа — напоминание не придёт (отключается в
`/reminders`). В самом напоминании есть кнопки «Записать» и «Через 15 минут».

**Сводка.** `/stats` — среднее, разброс, доля измерений в целевом диапазоне,
распределение по категориям с бар-чартом, разбивка по времени суток (утро /
день / вечер / ночь — то, что врач спросит первым), динамика по дням
спарклайном и сравнение с предыдущим таким же периодом. Период переключается
кнопками: неделя / месяц / 3 месяца / всё время.

**Графики.** `/chart` — картинка с давлением и пульсом. Пульс рисуется
отдельной панелью, а не второй осью Y: две шкалы на одном поле дают ложные
пересечения. Длинные периоды сворачиваются в суточные средние с полосой
разброса за день. Цвета проверены на различимость при дальтонизме.

**Выгрузка для врача.** `/export` — PDF формата A4: шапка, средние, разброс,
доля в цели, распределение по категориям, разбивка по времени суток, график и
таблица всех измерений с комментариями. Или CSV, если врач просит таблицу
(открывается в Excel без плясок с кодировкой).

**Настройки.** `/target 130/80` — целевые значения, которые назвал врач.
`/tz Europe/Berlin` — часовой пояс. `/about` — шкала категорий и честные
оговорки про то, чем бот не является.

## Запуск

Нужен только Python 3.10+ и токен бота от [@BotFather](https://t.me/BotFather)
(в Telegram: `/newbot` → имя → username → он пришлёт строку вида
`8123456789:AAH-…`).

**Одной командой.** Скрипт сам создаст окружение, поставит зависимости,
спросит токен и запустит бота:

```bash
./run.sh            # macOS и Linux
```

Под Windows — двойной клик по `run.bat`. Токен сохранится в файл `.env`, при
следующих запусках его не спросят. Бот работает, пока открыто окно терминала;
остановить — Ctrl+C.

**Вручную**, если хочется контролировать шаги:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # и вписать BOT_TOKEN
python -m bot.main
```

Бот держит данные в `data/pressure.db`. Хочешь перенести дневник на другую
машину — скопируй этот файл.

### Переменные окружения

| Переменная   | По умолчанию        | Зачем                                        |
|--------------|---------------------|----------------------------------------------|
| `BOT_TOKEN`  | —                   | Токен от [@BotFather](https://t.me/BotFather), обязателен |
| `DB_PATH`    | `data/pressure.db`  | Файл базы SQLite                             |
| `DEFAULT_TZ` | `Europe/Moscow`     | Часовой пояс новых пользователей и напоминаний |
| `LOG_LEVEL`  | `INFO`              | `DEBUG` / `INFO` / `WARNING`                 |

### Команды

| Команда              | Что делает                                       |
|----------------------|--------------------------------------------------|
| `120/80 68`          | записать измерение (просто текстом, без команды) |
| `/add`               | пошаговый ввод                                   |
| `/stats`             | сводка с переключением периода                   |
| `/chart`             | график давления и пульса                         |
| `/last`              | последние 10 измерений с кнопками удаления       |
| `/undo`, `/del 42`   | удалить последнее / по номеру                    |
| `/remind 08:00`      | напоминать каждый день в это время               |
| `/remind off`        | выключить все напоминания                        |
| `/reminders`         | список напоминаний и настройки                   |
| `/export`            | PDF для врача или CSV                            |
| `/target 130/80`     | целевые значения                                 |
| `/tz Europe/Moscow`  | часовой пояс                                     |
| `/about`, `/help`    | шкала категорий · все команды                    |

## Как всё устроено

```
run.sh, run.bat   запуск в одну команду: окружение, зависимости, токен, старт
bot/
  main.py         точка входа: бот, диспетчер, планировщик, long polling
  config.py       чтение .env
  db.py           SQLite-хранилище
  parsing.py      разбор текста: давление, пульс, дата, время, комментарий
  classify.py     шкала ESC/ESH, предупреждения, целевые значения
  stats.py        периоды, агрегаты, текст сводки
  charts.py       PNG-графики и PDF для врача (matplotlib)
  export.py       CSV и текстовый отчёт
  formatting.py   даты, карточки измерений, спарклайны
  keyboards.py    инлайн-клавиатуры
  reminders.py    планировщик напоминаний
  middlewares.py  автосоздание пользователя, локальное «сейчас»
  handlers/       common · entry · reports · export · reminders
tests/            разбор текста, шкала, агрегаты, хранилище,
                  напоминания, графики, смоук-тесты хендлеров
```

Время измерения хранится строкой `YYYY-MM-DD HH:MM` в часовом поясе владельца:
дневник ведётся по местным часам, а такой формат сравнивается лексикографически,
поэтому выборка за период — обычный `BETWEEN`. Данные разделены по `user_id` —
один процесс спокойно обслуживает нескольких человек, у каждого свои измерения,
напоминания, цель и часовой пояс.

Состояние напоминаний живёт в БД, а не в памяти, поэтому перезапуск бота не
приводит ни к потерянным, ни к задвоенным сообщениям. Если бот был выключен в
момент напоминания, он отправит его при старте — но только если опоздание
меньше 20 минут, чтобы не будить в полночь напоминанием из утра.

Без matplotlib бот работает: `/stats` и CSV на месте, вместо PDF приходит тот же
отчёт текстом, а `/chart` честно говорит, чего не хватает.

## Тесты

```bash
python -m unittest discover -s tests -t .
```

111 тестов, сети не требуют: хендлеры прогоняются через диспетчер с фейковым
ботом, который вместо HTTP-запросов записывает ответы, а планировщику
подставляется время, чтобы проверить и часовые пояса, и защиту от повторов.

## Важное

Бот — дневник, а не врач. Он не ставит диагнозов, не назначает и не отменяет
лекарства. Категории показываются по шкале ESC/ESH для измерений на приёме;
дома пороги ниже — гипертонией считают средние домашние значения от 135/85,
поэтому цель по умолчанию именно такая. Один высокий замер ничего не значит,
важна картина за недели — её и собирает `/stats`.

При давлении от 180/120, боли в груди, одышке, слабости в руке или ноге,
нарушении речи — это скорая (103), а не запись в дневнике.

## Что можно докрутить

- Лекарства: отметка «принял таблетку» и связка с цифрами
- Вес, сатурация, сахар — теми же карточками
- Экспорт в Google Sheets или отправка PDF врачу по расписанию
- Импорт из тонометров с Bluetooth
